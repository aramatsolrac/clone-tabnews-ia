# Project: clone-tabnews-ia

This is a clone of [TabNews](https://tabnews.com.br) built for [curso.dev](https://curso.dev) using AI agents.

## Tech Stack
- **Framework**: Next.js (App Router)
- **React**: Latest
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Linting**: ESLint with Next.js config

## Project Structure
- `app/` - Next.js App Router pages and components
- `public/` - Static assets

## Commands
- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run start` - Start production server
- `npm run lint` - Run ESLint

## Important Notes
- This project uses a newer Next.js version with breaking changes from previous versions
- Always refer to the Next.js documentation in `node_modules/next/dist/docs/` for current APIs and conventions
- Heed deprecation notices in the Next.js documentation
